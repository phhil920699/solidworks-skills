# SolidWorks 曲面编辑

## R — 原文 (Reading)

> “缝合缝隙公差最大约 0.1 毫米，间隙超过 0.1 就无法缝合。”
>
> — 《曲面编辑》系列视频

## I — 方法论骨架 (Interpretation)

曲面编辑把零厚度片体变成可用的实体或光顺模型：裁剪（标准/相互）、延伸、缝合、圆角、删除面、加厚、曲面切除。缝合把多个面合并，封闭后可勾“创建实体”；蓝色边是未缝合边界，黑色边是已缝合边，圆角只能做在黑边；开放曲面用加厚转实体，封闭曲面用缝合转实体。

## A1 — 应用示例 (Application Example)

### 示例 1：相互裁剪
- 两片相交曲面用“相互”一次裁掉重叠段。

### 示例 2：延伸 + 成形到面
- 放样曲面边线延伸“成形到另一曲面”。

### 示例 3：圆柱封口成实体
- 圆柱侧面 + 上下平面区域封口，缝合勾“创建实体”。

### 示例 4：缝合后变半径圆角
- 两拉伸面先缝合出黑边，再做变半径 20→10→15 圆角。

### 示例 5：曲面切除
- 48×48×48 立方体用基准面切掉一角。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 多个曲面需要合并、封闭或转成实体。
2. 曲面需要裁剪、延伸、圆角、修补。
3. 需要把开放曲面加厚成实体，或用曲面切除实体。

### 语言信号

- “曲面怎么缝合 / 转实体”
- “曲面圆角做不上”
- “曲面怎么裁剪 / 延伸 / 加厚”
- “solidworks knit surface / thicken / trim”

### 与相邻 skill 的区分

- 与曲面创建 skill 的区别：本卡负责已有曲面的修改和实体化。
- 与草图/特征 skill 的区别：这里处理的是曲面片体而非实体特征。

## E — 可执行步骤 (Execution)

**必需输入**：已创建的曲面/实体；目标操作（裁剪/延伸/缝合/圆角/删除/加厚/切除）。

**交付物与完成标准**：曲面被正确修剪、合并、光顺或转为实体，无自相交和未缝合间隙。

1. 判断操作与输入对象。
   - 判停：裁剪必须同时有被裁剪面和裁剪工具。
2. 执行裁剪/延伸/缝合/圆角/删除/加厚/切除。
   - 判停：圆角前必须先缝合出黑边。
3. 检查间隙与自相交。
   - 判停：缝合间隙 >0.1mm 会失败；加厚过大会自相交。
4. 转实体。
   - 开放曲面加厚；封闭曲面缝合勾“创建实体”。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 曲面还没有创建，需要先建曲面时。
- 只需要二维草图或实体特征编辑时。

### 视频中演示/警告的失败模式

- 间隙 0.15 > 0.1 缝合失败。
- 成形到面时目标面太小或太远。
- 未缝合的两个面点圆角选不中。
- 加厚过大导致自相交。
- 删除并填补的新面不光顺。

### 本课程的盲点 / 未覆盖

- 未深入曲面公差、复杂修补和逆向工程场景。

## 视觉核验（界面要点）

- 缝合面板含“创建实体”勾选项与缝隙公差检查；“显示范围内的间隙”用于排查超差。
- 曲面圆角只作用于缝合后的黑色边线；蓝色边为未缝合边界。
- 高清核验确认“缝合→创建实体”“加厚”两条实体化路径的界面标签与卡片一致。
