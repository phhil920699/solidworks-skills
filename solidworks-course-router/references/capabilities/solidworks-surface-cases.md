# SolidWorks 曲面综合案例

## R — 原文 (Reading)

> “曲面造型无严格标准、无图纸，尺寸灵活，可先自由发挥再固定。”
>
> — 《曲面综合案例》系列视频

## I — 方法论骨架 (Interpretation)

曲面综合案例把曲线、曲面创建和曲面编辑串成完整流程：画曲线/草图 → 建曲面 → 裁剪补面 → 镜像 → 缝合 → 加厚/创建实体。过渡面必须先有两侧结构再补中间，补面要与相邻面做相切或曲率；旋转截面上/下边线必须水平；圆角尽量在加厚前做；细节（螺纹/孔）放实体特征里做。

## A1 — 应用示例 (Application Example)

### 示例 1：耳机
- 回转 + 过渡面 + 沉槽 + 加厚的中空曲面件。

### 示例 2：握力器
- 三视图图纸建模，重点训练过渡补面与相切。

### 示例 3：瓜子
- 放样/边界三草图机体 + 分割线做花纹与上色。

### 示例 4：可乐瓶
- 旋转瓶体 + 小蛮腰边界引导线 + 瓶底凹槽阵列 + 螺纹。

### 示例 5：花瓶
- 扫描 + 引导线，先自由调形状再回草图按当前数值取整。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 要完整做一个曲面产品（瓶子、耳机、把手、握力器）。
2. 多个曲面特征需要编排成实体化流程。
3. 需要在曲面上做花纹、分割线、螺纹等细节。

### 语言信号

- “这个曲面产品怎么建模”
- “可乐瓶 / 耳机 / 花瓶怎么画”
- “曲面加厚 / 缝合 / 阵列 / 螺纹怎么做”
- “solidworks surface modeling case”

### 与相邻 skill 的区分

- 与单个曲面命令 skill 的区别：本卡强调案例级编排和过渡面策略。
- 与装配体 skill 的区别：这里仍是零件级曲面造型。

## E — 可执行步骤 (Execution)

**必需输入**：产品外形参考或三视图；主要曲面分块思路。

**交付物与完成标准**：完整、光顺、可加厚/转实体的曲面模型，或已实体化的产品模型。

1. 拆解产品为回转体/放样体/扫描体等结构。
2. 先做两侧/主体结构，再补中间过渡面。
   - 判停：补面必须与相邻面做相切/曲率，否则镜像后不光顺。
3. 裁剪、镜像、阵列。
   - 判停：裁剪优先“标准”，避免“相互”自动缝合影响阵列。
4. 缝合 + 加厚/创建实体。
5. 把螺纹、孔等细节放到实体特征阶段完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需要单个曲面命令，不需要完整案例流程时。
- 已经进入装配、仿真或出图阶段时。

### 视频中演示/警告的失败模式

- 放样/边界选边线无绿色控制点。
- 裁剪“保留/移除”选错整面被切掉。
- 填充/放样边线未设相切导致生硬。
- 整体画成一根样条导致后期无分割边线。
- 调整草图时扫描曲面卡顿。

### 本课程的盲点 / 未覆盖

- 未覆盖工业级 A 面、拔模分析、可制造性评估和复杂分模。

## 视觉核验（界面要点）

- 可乐瓶案例特征树顺序（示例）：旋转1 → 圆角1 → 拉伸切除1 → 镜像1 → 异型孔向导1 → 倒角1 → 外观。
- 异型孔向导面板：类型/标准/尺寸下拉、终止条件（穿透/指定深度）、位置（3D草图/面）、自动尺寸。
- 综合案例面板文字较多，高清核验主要确认特征树结构与关键面板标题；细节参数仍需对照具体图纸。
