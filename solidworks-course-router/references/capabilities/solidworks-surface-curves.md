# SolidWorks 曲面曲线创建

## R — 原文 (Reading)

> “曲面必须先靠曲线搭建，曲线学不好就无法建曲面。”
>
> — 《曲面建模基础知识》00:00–02:00

## I — 方法论骨架 (Interpretation)

曲面曲线是曲面建模的骨架：二维/三维样条、螺旋线、涡状线、投影曲线、交叉曲线、面部曲线、曲面偏移曲线、组合曲线、分割线。样条质量用曲率梳判断；螺旋线由螺距/圈数/高度三选二；投影沿绘图面法线；交叉曲线直接提取两面交线。

## A1 — 应用示例 (Application Example)

### 示例 1：扭转花纹杯
- 底圆 + 两个多边形端点连样条 → 放样 → 平面区域封底 → 缝合 → 圆角 → 加厚。

### 示例 2：绕环螺旋线
- 扫描曲面 + 扭转做扭转曲面，与铁环面求交叉曲线得到螺旋线。

### 示例 3：弹簧
- 螺旋线 + 两端水平直线组合成曲线 → 扫描成实体弹簧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 需要画光滑的样条轮廓、螺旋线、投影或交线。
2. 样条曲线不光滑，需要判断曲率质量。
3. 曲面建模前需要准备曲线骨架。

### 语言信号

- “样条曲线怎么画 / 曲率怎么调”
- “螺旋线 / 涡状线参数怎么设”
- “投影曲线、交叉曲线、分割线怎么选”
- “solidworks spline / helix / intersection curve”

### 与相邻 skill 的区分

- 与草图 skill 的区别：本卡专注曲面所需的 3D 曲线和高级曲线命令。
- 与曲面创建 skill 的区别：本卡产出曲线，曲面创建把曲线变成面。

## E — 可执行步骤 (Execution)

**必需输入**：目标曲线类型；参考草图/曲面/实体面；参数（螺距/圈数/偏移距离等）。

**交付物与完成标准**：可作为放样/扫描输入的合格曲线或 3D 草图。

1. 确定曲线类型和参考几何。
   - 完成标准：明确用样条、螺旋、投影还是交线。
2. 绘制或生成曲线。
   - 完成标准：曲线端点/控制点位置正确。
3. 检查曲率或几何关系。
   - 完成标准：样条曲率梳平滑无突增；螺旋参数满足需求。
   - 判停：投影超出曲面时超界不投影，需调整草图或方向。
4. 必要时组合/分割。
   - 完成标准：得到可被后续特征直接引用的单一曲线或分割面。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需要普通二维草图、或已有完整模型无需曲线时。
- 做装配体配合时。

### 视频中演示/警告的失败模式

- 样条打点过多导致曲率突变。
- 3D 草图端点未捕捉到位。
- 可变螺距把“圈数”当叠加值。
- 开放草图投影超出曲面或双向投影。
- 分割线用未超出曲面的开放直线。

### 本课程的盲点 / 未覆盖

- 课程未深入 G2/G3 曲率连续、曲面品质分析和复杂拓扑曲线编辑。

## 视觉核验（界面要点）

- 草图模式右下状态栏显示“草图模式”；特征树含三个基准面与草图节点。
- 曲线类命令 PropertyManager 标题随命令变化（如“样条曲线”），螺旋线面板含螺距/圈数/高度、起始角度与方向。
- 部分视频高清核验中界面文字过小或画面切换频繁，UI 细节置信度有限；建议实际使用时对照面板确认。
