# SolidWorks 草图绘制与约束

## R — 原文 (Reading)

> “尺寸约束就是控制它的一个长度，几何约束就是控制草图形状、草图实体的位置和状态。”
>
> — 《草图约束与实战》00:50–02:40

## I — 方法论骨架 (Interpretation)

草图建模分两步：先用直线、矩形、圆、槽口等命令搭出大致形状，再用几何约束（水平/竖直/重合/相切/相等/对称）和尺寸约束把形状完全定义。对称图形画一半再镜像最省事；圆角/倒角尽量留到特征阶段。

## A1 — 应用示例 (Application Example)

### 示例 1：对称外轮廓 + 两内圆
- 类型：原视频实战。先画外围，补两内圆，加相切与相等约束，构造线镜像，最终图形完全定义（黑色）。

### 示例 2：一星题三步拉伸支架
- 类型：原视频练习题。底板、立板、半圆三部分分别草图 + 镜像 + 拉伸。

### 示例 3：二星题瓶体 + 把手
- 类型：原视频练习题。旋转 + 抽壳 + 完整圆角做瓶体，路径 + 垂直基准面 + 穿透 + 扫描做把手。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 刚开始画 SolidWorks 草图，不知道选哪个基准面和命令。
2. 草图是蓝色、可以拖动，想要完全定义。
3. 需要画对称件、槽口、扫描把手等特征。

### 语言信号

- “草图怎么完全定义 / 为什么还是蓝色”
- “对称图形怎么画”
- “扫描的路径和轮廓怎么设置”
- “solidworks sketch fully defined / symmetry”

### 与相邻 skill 的区分

- 与曲面 skill 的区别：本 skill 负责二维草图和基础实体特征，曲面属于后续建模阶段。
- 与装配体配合 skill 的区别：这里只做零件级草图，不处理零件间约束。

## E — 可执行步骤 (Execution)

**必需输入**：目标图纸或尺寸；草图基准面；需要使用的命令类型。

**交付物与完成标准**：完全定义的黑色草图，可正确拉伸/旋转/扫描为实体或曲面。

1. 确认基准面与原点，进入草图。
   - 完成标准：在正确平面上开始绘图。
2. 用绘制命令搭大致形状。
   - 完成标准：轮廓基本形状就位，暂不求精确。
3. 加几何约束与尺寸约束。
   - 完成标准：图形变黑，无蓝色可拖动元素。
   - 判停：若对称件仍可左右漂移，补“相等”或镜像到中心线。
4. 对称件画一半 + 构造线镜像。
   - 完成标准：两侧联动，标注量减少。
5. 检查并退出草图。
   - 完成标准：状态栏/颜色确认完全定义。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只做尺寸查询、图纸标注或纯 3D 曲面造型时。
- 已经进入装配体配合阶段时。

### 视频中演示/警告的失败模式

- 草图欠约束留蓝色。
- 点线“重合”误当点在线上。
- 滥用“固定”锁死草图。
- 多选实体没按 Ctrl。
- 裁剪未交叉整条被删。
- 扫描端面未对齐。

### 本课程的盲点 / 未覆盖

- 课程以快速上手为主，对草图最佳实践、公差、过定义修复和复杂参数化驱动讲得较浅。

## 视觉核验（界面要点）

- PropertyManager 标题随命令变化：直线命令显示“直线”，含“起点/终点”坐标；圆命令显示“圆”，含“中心点/直径”。
- 绘制面板含“添加几何关系/自动添加几何关系”勾选项；“完全定义”可作为草图完成度检查。
- 特征树标准结构：前视/上视/右视基准面 → 草图 → 拉伸；草图编辑时顶部有“退出草图”。
- 高分辨率核验基本确认命令名与基准面术语，与卡片一致；其余小字部分仍受分辨率限制。
