# SolidWorks Codex Skills

A collection of Codex skills distilled from a 46-video SolidWorks course. These skills cover the complete workflow from 2D sketches and surface modeling to assembly mates.

## Skills

| Skill | Purpose |
|---|---|
| `solidworks-sketch` | Sketch drawing, constraints, and fully-defined checks |
| `solidworks-surface-curves` | Splines, helixes, projected/intersection/split curves |
| `solidworks-surface-create` | Extrude/revolve/sweep/loft/boundary/fill surfaces |
| `solidworks-surface-edit` | Trim, extend, knit, fillet, thicken, cut-with-surface |
| `solidworks-surface-cases` | Complete surface products (bottle, earbuds, handle) |
| `solidworks-assembly-mates` | Standard, advanced, and mechanical mates |
| `solidworks-course-router` | Source router that loads the correct capability card |

## Installation

Copy each skill folder into your Codex skills directory, typically:

```
C:\Users\<you>\.codex\skills\
```

Or use the skill installer to install from this repository.

## Scope

These skills cover part modeling and assembly mating in SOLIDWORKS. They do **not** cover drawings, sheet metal, motion studies, or FEA.
