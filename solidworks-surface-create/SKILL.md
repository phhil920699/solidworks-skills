# SolidWorks 曲面创建

## R — 原文 (Reading)

> “曲面命令生成的是曲面实体，与对应实体特征操作类似，但结果中空。”
>
> — 《曲面创建》系列视频

## I — 方法论骨架 (Interpretation)

曲面创建命令把草图/曲线变成零厚度片体：拉伸、旋转、扫描、放样、平面区域、填充、边界、等距。拉伸/旋转/扫描与实体凸台类似但中空；放样要求截面≥2并按顺序对齐绿色对应点；平面区域要求边线共面；填充曲面要求封闭轮廓；边界曲面≈高质量放样；等距距离为 0 可复制面。

## A1 — 应用示例 (Application Example)

### 示例 1：旋转花瓶
- 开放样条截面绕轴旋转成瓶身，后期加厚成实体。

### 示例 2：扫描花瓶/绞龙/弹簧
- 扫描加引导线改变轮廓，或用扭转生成螺旋形状。

### 示例 3：变截面弹簧
- 螺旋线作中心线，圆形→六边形截面放样过渡。

### 示例 4：两曲面间过渡
- 3D 草图连点补齐封闭轮廓，再用填充曲面 + 相切接合。

### 示例 5：复制提取面
- 等距曲面距离输 0，原位复制出辅助曲面实体。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 需要从草图/曲线生成曲面，或把曲面加厚成实体。
2. 需要在多个截面之间放样/边界成型。
3. 需要复制、偏置或填充曲面。

### 语言信号

- “拉伸曲面 / 旋转曲面怎么用”
- “放样曲面怎么选截面”
- “边界曲面和放样有什么区别”
- “solidworks surface loft / boundary / fill”

### 与相邻 skill 的区分

- 与曲面曲线 skill 的区别：本卡把曲线变成面，曲面曲线负责生成曲线。
- 与曲面编辑 skill 的区别：本卡只创建，不裁剪、缝合、加厚或转实体。

## E — 可执行步骤 (Execution)

**必需输入**：草图/曲线/截面；命令类型；方向和参数。

**交付物与完成标准**：生成预期的曲面实体，截面方向正确、对应点对齐、曲面质量合格。

1. 确认输入曲线/草图与命令类型。
2. 选择轮廓、路径、引导线或截面。
   - 判停：扫描加引导线时轮廓不能尺寸锁死，需用穿透/重合约束。
3. 设置方向、角度、相切等参数并预览。
   - 判停：放样绿色对应点未对齐会扭曲，需手动对齐。
4. 确认生成，检查曲面是否为中空片体而非实体。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需要实体特征，不需要曲面过渡时。
- 已经进入曲面裁剪、缝合、加厚等编辑阶段时。

### 视频中演示/警告的失败模式

- 把旋转生成的圆环误判为实体，实际是中空曲面。
- 加引导线前把轮廓尺寸锁死导致报错。
- 放样对应点未对齐导致扭曲/褶皱。
- 平面区域所选边线不共面。
- 填充曲面边线开放不封闭。

### 本课程的盲点 / 未覆盖

- 未深入讨论曲面品质（G2/G3）、公差和复杂分面策略。

## 视觉核验（界面要点）

- 放样/边界面板依赖“截面”选择顺序与绿色对应点对齐，核验确认对应点未对齐会导致曲面扭曲。
- 拉伸/旋转曲面面板标题与实体特征类似（拉伸-凸台/基体），但生成结果为曲面实体。
- 高清核验确认命令入口路径与卡片一致；具体参数值需按模型实际设置。
